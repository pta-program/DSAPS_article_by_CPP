# 7-53 两个有序序列的中位数

- **分值：** 25分

## 题目描述

已知有两个等长的非降序序列S1, S2, 设计函数求S1与S2并集的中位数。有序序列$$A_0, A_1, \cdots, A_{N-1}$$的中位数指$$A_{(N-1)/2}$$的值,即第$$\lfloor(N+1)/2\rfloor$$个数（$$A_0$$为第1个数）。

## 输入格式

输入分三行。第一行给出序列的公共长度N（0$$<$$N$$\le$$100000），随后每行输入一个序列的信息，即N个非降序排列的整数。数字用空格间隔。

## 输出格式

在一行中输出两个输入序列的并集序列的中位数。

## 输入样例1
```
5
1 3 5 7 9
2 3 4 5 6
```

## 输出样例1
```
4
```

## 输入样例2
```
6
-100 -10 1 1 1 1
-50 0 2 3 4 5
```

## 输出样例2
```
1
```
